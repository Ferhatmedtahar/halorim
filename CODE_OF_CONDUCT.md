# Code of Conduct

We want Halorim to be a welcoming project for everyone.

## Our standards

- Be respectful and assume good faith.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the community.

Unacceptable behavior includes harassment, personal attacks, discriminatory language, trolling,
publishing others' private information, and anything else that would be inappropriate in a
professional setting.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, issues, and other contributions that
violate this code, and may ban contributors who repeatedly do so.

Report problems privately through GitHub (a private security advisory or a direct message to a
maintainer). Reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.
